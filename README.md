## Como rodar

### Pré-requisitos
Java 17, Maven, Node.js, Expo Go.

### Backend (Windows, Linux ou macOS)
1. Abra o terminal na pasta `backend`.
2. Rode `mvn spring-boot:run`.

### Frontend (Windows, Linux ou macOS)
1. Abra outro terminal na pasta `frontend`.
2. Rode `npm install`.
3. Rode `npx expo start --tunnel` (funciona em qualquer rede Wi-Fi).
4. Leia o QR Code com o aplicativo Expo Go no celular (iOS ou Android).

### Comandos para reset de máquinas Windows da Faculdade
Abra o PowerShell e digite:
`Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned`
Se pedir confirmação, digite `S` e dê Enter.
